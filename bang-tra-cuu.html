3. Bảng Tra Cứu HTML Toàn Diện

Đầy đủ các thẻ HTML từ cấu trúc tài liệu, định dạng văn bản, liên kết, đa phương tiện, bảng, biểu mẫu nhập liệu và thẻ ngữ nghĩa.

3.1 Cấu Trúc Tài Liệu & Khung Trang Web

<!DOCTYPE html> Cấu Trúc Trang

Khai báo phiên bản tài liệu chuẩn HTML5 để trình duyệt hiển thị ở chế độ tiêu chuẩn (standards mode).

HTML5 
<!DOCTYPE html>
<html lang="vi"> Thẻ Gốc (Root)

Phần tử gốc bao bọc toàn bộ nội dung trang web. Thuộc tính lang xác định ngôn ngữ hiển thị.

HTML5 
<html lang="vi">
  ...
</html>
<head> Phần Đầu Trang

Chứa metadata thông tin trang, tiêu đề, liên kết file CSS, phông chữ (không hiển thị trực tiếp ra màn hình).

HTML5 
<head>
  <meta charset="UTF-8">
  <title>Tiêu Đề Trang</title>
</head>
<title> Tiêu Đề Tab

Đặt tiêu đề cho trang web, hiển thị trên tab của trình duyệt và kết quả tìm kiếm Google (SEO).

HTML5 
<title>Học HTML Cơ Bản Đến Nâng Cao</title>
<meta> Siêu Dữ Liệu

Khai báo bảng mã ký tự UTF-8, cấu hình viewport co giãn responsive trên điện thoại, mô tả trang SEO.

HTML5 
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Mô tả trang web chuẩn SEO">
<link> Liên Kết Ngoài

Nhúng file CSS bên ngoài, favicon, phông chữ từ Google Fonts vào trang HTML.

HTML5 
<link rel="stylesheet" href="style.css">
<link rel="icon" href="favicon.ico">
<script> Nhúng JavaScript

Nhúng mã JavaScript thực thi trực tiếp hoặc tải từ file .js bên ngoài (hỗ trợ defer / async).

HTML5 
<script src="app.js" defer></script>
<body> Thân Trang Web

Chứa toàn bộ nội dung trực quan mà người dùng nhìn thấy và tương tác trên trang web.

HTML5 
<body>
  <h1>Xin chào thế giới!</h1>
  <p>Nội dung website ở đây.</p>
</body>

3.2 Tiêu Đề, Đoạn Văn & Định Dạng Chữ

<h1> - <h6> Tiêu Đề (Headings)

6 cấp bậc tiêu đề từ lớn nhất (h1) đến nhỏ nhất (h6). Mỗi trang web nên có duy nhất 1 thẻ h1 chuẩn SEO.

HTML5 
<h1>Tiêu Đề Cấp 1 (Chính)</h1>
<h2>Tiêu Đề Cấp 2 (Mục lớn)</h2>
<h3>Tiêu Đề Cấp 3 (Mục con)</h3>
<p> Đoạn Văn Bản

Định nghĩa một đoạn văn bản (Paragraph). Tự động có khoảng cách trên và dưới (margin) mặc định.

HTML5 
<p>Đây là một đoạn văn bản giới thiệu nội dung bài học.</p>
<span> Inline Container

Thẻ nội dòng vô ngữ nghĩa, dùng để bọc một cụm từ cần đổi màu sắc, phông chữ hoặc gán hiệu ứng CSS.

HTML5 
<p>Giá bán: <span style="color: red; font-weight: bold;">299.000đ</span></p>
<strong> & <b> In Đậm Chữ

in đậm chữ với ý nghĩa ngữ nghĩa nhấn mạnh quan trọng. chỉ đơn thuần in đậm thị giác.

HTML5 
<p>Vui lòng <strong>không chia sẻ mật khẩu</strong> cho bất kỳ ai.</p>
<em> & <i> In Nghiêng Chữ

in nghiêng với ngữ nghĩa nhấn giọng. chỉ đơn thuần in nghiêng thị giác (thường dùng cho icon).

HTML5 
<p>Học lập trình cần <em>kiên trì thực hành</em> mỗi ngày.</p>
<mark> Tô Sáng Nổi Bật

Tô màu nền vàng dạ quang nổi bật cho một cụm từ tìm kiếm hoặc thông tin quan trọng.

HTML5 
<p>Kết quả tìm thấy: <mark>CSS Flexbox</mark> trong bài 00.</p>
<del> & <ins> Gạch Bỏ & Thêm Mới

gạch ngang chữ bị xóa (giá cũ). gạch chân chữ mới được thêm vào (giá khuyến mãi).

HTML5 
<p>Giá gốc: <del>500.000đ</del> - Giảm còn: <ins>350.000đ</ins></p>
<sub> & <sup> Chỉ Số Dưới / Trên

tạo chỉ số dưới (công thức hóa học H2O). tạo chỉ số trên (lũy thừa x2, chú thích).

HTML5 
<p>Nước: H<sub>2</sub>O | Diện tích: 100 m<sup>2</sup></p>
<pre> & <code> Mã Nguồn Máy Tính

biểu thị đoạn mã lập trình. 

 giữ nguyên khoảng trắng và ký tự xuống dòng gốc.

          

            

              HTML5
              
            

            
<pre><code>function hello() {
  console.log('Hello World!');
}</code></pre>
<blockquote> Đoạn Trích Dẫn

Khối trích dẫn một câu danh ngôn hay đoạn văn dài từ nguồn khác, thường có thụt lề đầu dòng.

HTML5 
<blockquote cite="https://w3schools.com">
  <p>Học thiết kế web giúp bạn tạo ra những sản phẩm kỳ diệu.</p>
</blockquote>
<br> & <hr> Xuống Dòng & Phân Cách


ngắt dòng trong đoạn văn.

tạo đường kẻ ngang phân tách chủ đề nội dung (thematic break).

HTML5 
<p>Dòng thứ nhất.<br>Dòng thứ hai.</p>
<hr>

3.3 Liên Kết & Đa Phương Tiện (Links, Images & Media)

<a href="..."> Thẻ Siêu Liên Kết

Tạo liên kết chuyển trang web, nhảy đến thẻ neo (#id), gọi điện thoại (tel:) hoặc gửi email (mailto:).

HTML5 
<a href="https://google.com" target="_blank" rel="noopener noreferrer">Mở Google</a>
<a href="#secCss">Xem CSS</a>
<img src="..." alt="..."> Hình Ảnh

Chèn ảnh vào trang. Thuộc tính alt là bắt buộc (mô tả ảnh khi lỗi và hỗ trợ SEO/A11y). Hỗ trợ loading='lazy'.

HTML5 
<img src="avatar.jpg" alt="Ảnh đại diện cá nhân" width="200" height="200" loading="lazy">
<audio controls> Trình Phát Âm Thanh

Nhúng file âm thanh (MP3, WAV, OGG) trực tiếp với giao diện phát nhạc, tạm dừng, âm lượng native.

HTML5 
<audio controls>
  <source src="song.mp3" type="audio/mpeg">
  Trình duyệt của bạn không hỗ trợ thẻ audio.
</audio>
<video controls> Trình Phát Video

Nhúng file video (MP4, WebM) kèm thanh điều khiển, hình thu nhỏ poster, tự động phát hoặc lặp lại.

HTML5 
<video width="640" height="360" controls poster="preview.jpg">
  <source src="video.mp4" type="video/mp4">
</video>
<iframe> Khung Nhúng Trang Web

Nhúng một trang web, bản đồ Google Maps, hoặc video YouTube vào một khung độc lập trên trang.

HTML5 
<iframe src="https://example.com" width="100%" height="400" sandbox="allow-scripts" title="Trang nhúng"></iframe>
<svg> Đồ Họa Vector SVG

Vẽ đồ họa vector sắc nét không bị vỡ hạt ở mọi độ phân giải màn hình, thường dùng cho biểu tượng icon.

HTML5 
<svg width="24" height="24" viewBox="0 0 24 24" fill="currentColor">
  <circle cx="12" cy="12" r="10"/>
</svg>

3.4 Danh Sách (Lists: ul, ol, li, dl)

<ul> & <li> Danh Sách Không Thứ Tự

Danh sách dấu đầu dòng (bullet points). Thường dùng làm danh sách bài viết, menu điều hướng navbar.

HTML5 
<ul class="nav-menu">
  <li>Trang Chủ</li>
  <li>Khóa Học</li>
  <li>Liên Hệ</li>
</ul>
<ol> & <li> Danh Sách Có Thứ Tự

Danh sách đánh số thứ tự tự động (1, 2, 3... hoặc A, B, C). Dùng cho các bước làm bài tập, công thức.

HTML5 
<ol start="1">
  <li>Đọc kỹ đề bài</li>
  <li>Code trong starter</li>
  <li>Đối chiếu solution</li>
</ol>
<dl>, <dt> & <dd> Danh Sách Mô Tả / Thuật Ngữ

Danh sách định nghĩa thuật ngữ:

là từ khóa/tên,
là dòng giải thích chi tiết của thuật ngữ đó.

HTML5 
<dl>
  <dt>HTML</dt>
  <dd>Ngôn ngữ đánh dấu siêu văn bản định hình cấu trúc.</dd>
  <dt>CSS</dt>
  <dd>Ngôn ngữ tạo phong cách làm đẹp giao diện.</dd>
</dl>

3.5 Bảng Dữ Liệu (HTML Tables: table, thead, tbody, tr, th, td)

<table> Cấu Trúc Đầy Đủ Bảng Dữ Liệu Chuẩn

Bảng dữ liệu hoàn chỉnh gồm (tiêu đề bảng), (phần đầu), (thân), (tổng kết).

HTML5 
<table border="1">
  <caption>Báo Cáo Doanh Thu</caption>
  <thead>
    <tr><th>Tháng</th><th>Doanh Thu</th></tr>
  </thead>
  <tbody>
    <tr><td>Tháng 1</td><td>10.000.000đ</td></tr>
  </tbody>
  <tfoot>
    <tr><th>Tổng</th><th>10.000.000đ</th></tr>
  </tfoot>
</table>
colspan & rowspan Gộp Ô Trong Bảng

Thuộc tính gộp ô: colspan='2' gộp 2 cột nằm ngang; rowspan='2' gộp 2 hàng nằm dọc theo chiều đứng.

HTML5 
<tr>
  <th colspan="2">Thông Tin Cá Nhân (Gộp 2 cột)</th>
</tr>
<tr>
  <td rowspan="2">Ảnh (Gộp 2 hàng)</td>
  <td>Họ Tên</td>
</tr>

3.6 Biểu Mẫu Nhập Liệu (HTML Forms & Inputs Toàn Diện)

<form action="..." method="..."> Thẻ Khung Biểu Mẫu

Gom nhóm các ô nhập dữ liệu gửi lên máy chủ. Phương thức phổ biến: method='POST' hoặc 'GET'.

HTML5 
<form action="/api/login" method="POST">
  ...
</form>
<label for="..."> Nhãn Mô Tả Ô Nhập

Gắn nhãn cho ô input qua thuộc tính for khớp với id của input. Bấm vào chữ label sẽ tự động focus vào input!

HTML5 
<label for="userEmail">Địa Chỉ Email:</label>
<input type="email" id="userEmail" name="email" required>
<input type="text | password"> Nhập Chữ & Mật Khẩu

type='text' nhập văn bản thường. type='password' tự động che dấu hoa thị chấm tròn bảo vệ mật khẩu.

HTML5 
<input type="text" placeholder="Họ và tên" maxlength="50">
<input type="password" placeholder="Nhập mật khẩu">
<input type="email | number"> Email & Con Số

type='email' tự kiểm tra định dạng @. type='number' chỉ cho phép số, có min, max, step.

HTML5 
<input type="email" placeholder="name@domain.com" required>
<input type="number" min="1" max="100" value="1" step="1">
<input type="checkbox | radio"> Hộp Kiểm & Nút Tròn

checkbox cho phép chọn nhiều mục. radio (cùng chung name) chỉ cho phép chọn 1 mục duy nhất.

HTML5 
<input type="checkbox" id="c1"><label for="c1">Tôi đồng ý</label>
<input type="radio" name="gender" value="male"> Nam
<input type="radio" name="gender" value="female"> Nữ
<input type="file | date | color"> Tập Tin, Ngày Tháng & Màu

type='file' chọn tệp tải lên (accept). type='date' chọn ngày trong lịch. type='color' mở bảng màu picker.

HTML5 
<input type="file" accept="image/*">
<input type="date">
<input type="color" value="#6366f1">
<textarea> Hộp Nhập Văn Bản Lớn

Ô nhập văn bản nhiều dòng dùng cho lời nhắn, nhận xét, mô tả bài viết. Tùy chỉnh số hàng (rows) và cột (cols).

HTML5 
<textarea rows="4" cols="50" placeholder="Nhập nội dung lời nhắn..."></textarea>
<select> & <option> Menu Thả Xuống (Dropdown)

Tạo danh sách thả xuống cho người dùng chọn một hoặc nhiều lựa chọn trong danh mục.

HTML5 
<select name="city">
  <option value="hn">Hà Nội</option>
  <option value="hcm" selected>TP. Hồ Chí Minh</option>
  <option value="dn">Đà Nẵng</option>
</select>
<button type="submit | button"> Nút Bấm Trong Form

type='submit' gửi dữ liệu form. type='reset' xóa trắng form. type='button' nút thường dùng cho JS.

HTML5 
<button type="submit">Gửi Biểu Mẫu</button>
<button type="button" onclick="doSomething()">Nút Tác Vụ</button>
<fieldset> & <legend> Nhóm Ô Nhập Có Viền Khung

Gom nhóm các ô nhập có liên quan trong form lại kèm theo dòng tiêu đề () nổi trên viền khung.

HTML5 
<fieldset>
  <legend>Thông Tin Giao Hàng</legend>
  <input type="text" placeholder="Địa chỉ">
</fieldset>
<datalist> Gợi Ý Tự Động Hoàn Thành

Cung cấp danh sách gợi ý tự động (autocomplete) khi người dùng gõ vào ô input nhưng vẫn cho phép gõ tự do.

HTML5 
<input list="browsers" placeholder="Chọn trình duyệt...">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Safari">
</datalist>

3.7 Thẻ HTML5 Semantic & Thẻ Tương Tác Hiện Đại

<header> Khối Đầu Trang

Chứa phần đầu trang, logo, thanh điều hướng chính, hoặc phần giới thiệu của một bài viết/card.

HTML5 
<header class="site-header">
  <a href="/" class="logo">⚡ DevWeb</a>
  <nav class="main-nav">...</nav>
</header>
<nav> Thanh Điều Hướng

Vùng chứa các liên kết điều hướng quan trọng (Menu chính, thanh phụ, phân trang).

4. Bảng Tra Cứu CSS3 Toàn Diện

Đầy đủ bộ chọn CSS, mô hình hộp Box Model, Flexbox, Grid, Typography, màu sắc gradients, chuyển động 3D và Media Queries responsive.

4.1 Bộ Chọn CSS (CSS Selectors)

* (Universal Selector) Bộ Chọn Phổ Quát

Chọn tất cả mọi phần tử HTML trên toàn trang. Thường dùng trong CSS Reset để đặt lại box-sizing và xóa margin/padding mặc định.

CSS 
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
.class (Class Selector) Bộ Chọn Theo Lớp

Chọn tất cả các phần tử có cùng tên class (bắt đầu bằng dấu chấm .). Có thể tái sử dụng cho nhiều phần tử.

CSS 
.card {
  background: #1e293b;
  border-radius: 12px;
  padding: 20px;
}
#id (ID Selector) Bộ Chọn Định Danh Duy Nhất

Chọn một phần tử duy nhất dựa trên thuộc tính id (bắt đầu bằng dấu thăng #). Có độ ưu tiên specificity cao hơn class.

CSS 
#main-nav {
  position: sticky;
  top: 0;
  z-index: 100;
}
element (Type Selector) Bộ Chọn Tên Thẻ

Chọn tất cả các phần tử HTML mang tên thẻ tương ứng (ví dụ: p, a, button, h1).

CSS 
p {
  line-height: 1.6;
  color: #94a3b8;
}
button {
  cursor: pointer;
}
A B vs A > B Hậu Duệ & Con Trực Tiếp

A B (cách nhau khoảng trắng): chọn mọi B nằm bên trong A bất kể cấp. A > B: chỉ chọn B là con trực tiếp cấp 1 của A.

CSS 
/* Mọi link bên trong nav */
nav a { color: #fff; }

/* Chỉ thẻ li là con cấp 1 của ul */
ul > li { list-style: none; }
A + B vs A ~ B Anh Em Liền Kề & Chung Cha

A + B: chọn phần tử B đứng ngay lập tức sau A. A ~ B: chọn mọi phần tử B đứng sau A cùng cha.

CSS 
/* Đoạn p đứng ngay sau thẻ h2 */
h2 + p {
  margin-top: 8px;
  font-weight: 500;
}

/* Mọi p đứng sau h2 */
h2 ~ p { color: #cbd5e1; }
[attribute] (Thuộc Tính) Bộ Chọn Thuộc Tính

Chọn phần tử dựa theo thuộc tính HTML hoặc giá trị của thuộc tính (so sánh bằng, bắt đầu, kết thúc hoặc chứa).

CSS 
input[type="email"] {
  border-color: #6366f1;
}
a[href^="https"] {
  color: #38bdf8;
}
img[src$=".png"] {
  filter: drop-shadow(0 2px 4px rgba(0,0,0,0.2));
}

4.2 Lớp Giả (Pseudo-classes) & Phần Tử Giả (Pseudo-elements)

:hover & :active Trạng Thái Rê Chuột & Nhấn

:hover kích hoạt khi con trỏ chuột rê lên phần tử. :active kích hoạt tại khoảnh khắc người dùng ấn chuột / chạm tay xuống.

CSS 
.btn-primary {
  transition: all 0.2s ease;
}
.btn-primary:hover {
  background: #4f46e5;
  transform: translateY(-2px);
}
.btn-primary:active {
  transform: translateY(0);
}
:focus & :focus-visible Trạng Thái Tiêu Điểm Bàn Phím

:focus kích hoạt khi ô nhập hoặc nút nhận focus. :focus-visible chỉ hiển thị viền tiêu điểm khi người dùng duyệt bằng bàn phím Tab (chuẩn A11y).

CSS 
input:focus {
  outline: none;
  border-color: #6366f1;
  box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.25);
}
button:focus-visible {
  outline: 2px solid #38bdf8;
  outline-offset: 2px;
}
:nth-child(n) & :not() Chọn Vị Trí & Loại Trừ

:nth-child(even / odd / 2n+1) chọn phần tử theo thứ tự số học (kẻ sọc bảng). :not(.active) chọn tất cả ngoại trừ class chỉ định.

CSS 
/* Kẻ sọc hàng chẵn trong bảng */
tr:nth-child(even) {
  background: rgba(255, 255, 255, 0.03);
}
/* Loại trừ nút đầu tiên */
.btn:not(:first-child) {
  margin-left: 8px;
}
::before & ::after Chèn Nội Dung Ảo

Tạo ra một phần tử con ảo đầu tiên hoặc cuối cùng (bắt buộc phải có content: '') dùng làm icon, đường kẻ, ruy-băng trang trí mà không làm bẩn HTML.

CSS 
.tag-pro::before {
  content: '★ ';
  color: #fbbf24;
}
.card::after {
  content: '';
  position: absolute;
  bottom: 0; left: 0;
  width: 100%; height: 3px;
  background: linear-gradient(90deg, #6366f1, #ec4899);
}
::placeholder & ::selection Chữ Gợi Ý & Bôi Đen Văn Bản

::placeholder tùy chỉnh màu và kiểu chữ cho dòng gợi ý ô input. ::selection đổi màu nền và màu chữ khi người dùng bôi đen văn bản.

CSS 
input::placeholder {
  color: #64748b;
  font-style: italic;
}
::selection {
  background: #6366f1;
  color: #ffffff;
}

4.3 Mô Hình Hộp (Box Model), Kích Thước & Đơn Vị Đo

box-sizing: border-box Cơ Chế Tính Kích Thước

Quy định chiều rộng và chiều cao phần tử đã bao gồm cả padding và border, ngăn ngừa vỡ layout khi thêm viền đệm.

CSS 
*,
*::before,
*::after {
  box-sizing: border-box;
}
margin (Margin Collapsing) Khoảng Cách Bên Ngoài

Tạo khoảng trống bao quanh phần tử. margin: auto giúp căn giữa theo chiều ngang trong block có width cụ thể.

CSS 
.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto; /* Căn giữa */
}
.card {
  margin-bottom: 24px;
}
padding Khoảng Đệm Bên Trong

Tạo khoảng cách giữa nội dung của phần tử và đường viền (border) của nó. Cú pháp tắt: top-bottom right-left.

CSS 
.button {
  padding: 12px 24px; /* 12px trên/dưới, 24px trái/phải */
}
.card-body {
  padding: 20px;
}
border & border-radius Đường Viền & Bo Tròn Góc

border định nghĩa độ dày, kiểu dáng và màu sắc viền. border-radius: 50% tạo hình tròn avatar hoàn hảo.

CSS 
.avatar {
  width: 80px;
  height: 80px;
  border: 2px solid #6366f1;
  border-radius: 50%; /* Hình tròn */
  object-fit: cover;
}
.badge {
  border-radius: 9999px; /* Viên thuốc pill */
}
width / min-width / max-width Chiều Rộng An Toàn Co Giãn

Sử dụng max-width kết hợp width: 100% giúp giao diện tự động co dãn hoàn hảo trên mọi kích thước màn hình điện thoại.

CSS 
.hero-card {
  width: 100%;
  max-width: 600px;
  min-height: 350px;
}
Đơn Vị: rem, em, %, vh, vw Đơn Vị Đo Hiện Đại

rem: tỷ lệ theo font gốc html (1rem = 16px). vw/vh: tỷ lệ theo chiều rộng/cao khung nhìn viewport (100vh = toàn màn hình).

CSS 
body { font-size: 1rem; }
h1 { font-size: 2.25rem; } /* 36px */
.hero-full { min-height: 100vh; }
.half-screen { width: 50vw; }
clamp() & calc() Hàm Tính Toán Kích Thước

calc() cho phép cộng trừ đơn vị khác nhau (100% - 40px). clamp(min, val, max) tạo cỡ chữ co giãn mượt mà theo màn hình.

CSS 
.responsive-heading {
  font-size: clamp(1.8rem, 4vw, 3rem);
}
.sidebar-content {
  width: calc(100% - 280px);
}

4.4 Hiển Thị (Display) & Định Vị (Positioning)

display: block / inline / inline-block Chế Độ Hiển Thị Cơ Bản

block: chiếm trọn 1 hàng riêng, nhận width/height. inline: nằm trên cùng 1 dòng, không nhận width/height. inline-block: nằm trên 1 dòng nhưng vẫn nhận width/height.

CSS 
.block-box { display: block; }
.inline-link { display: inline; }
.btn-tag {
  display: inline-block;
  width: 120px;
  padding: 8px 12px;
}
display: none vs visibility: hidden Ẩn Phần Tử Trên Trang

display: none ẩn hoàn toàn và loại bỏ phần tử khỏi dòng chảy (không chiếm diện tích). visibility: hidden chỉ làm tàng hình (vẫn giữ chỗ trống).

CSS 
.modal.is-closed {
  display: none;
}
.invisible-placeholder {
  visibility: hidden;
}
position: relative & absolute Định Vị Tương Đối & Tuyệt Đối

position: relative giữ nguyên vị trí ban đầu và làm gốc tọa độ cho con mang position: absolute định vị tự do theo top, right, bottom, left.

CSS 
.card {
  position: relative; /* Gốc tọa độ */
}
.badge-hot {
  position: absolute;
  top: 10px;
  right: 10px;
}
position: fixed vs sticky Cố Định Khung Nhìn & Ghim Cuộn

fixed: luôn cố định tại một tọa độ trên màn hình ngay cả khi cuộn trang. sticky: cuộn bình thường tới khi chạm ngưỡng top thì tự động dính lại.

CSS 
.chat-bubble {
  position: fixed;
  bottom: 20px; right: 20px;
  z-index: 999;
}
.navbar-sticky {
  position: sticky;
  top: 0;
  z-index: 100;
}
z-index & Stacking Context Thứ Tự Xếp Lớp Hiển Thị

Điều khiển phần tử nào nằm đè lên phần tử nào theo trục Z. Chỉ có tác dụng khi phần tử có position khác static.

CSS 
.dropdown-menu {
  position: absolute;
  z-index: 50; /* Nổi lên trên card */
}
.modal-backdrop {
  position: fixed;
  z-index: 1000;
}
overflow & text-overflow Xử Lý Tràn Nội Dung

overflow: hidden cắt bỏ nội dung thừa tràn ra ngoài. text-overflow: ellipsis tự động thêm dấu ba chấm (...) khi chữ dài tràn ô.

CSS 
.truncate-text {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  max-width: 250px;
}
.scrollable-box {
  overflow-y: auto;
  max-height: 400px;
}

4.5 Bố Cục 1 Chiều CSS Flexbox & Mini Interactive Studio

display: flex & flex-direction Kích Hoạt & Chiều Trục Chính

Biến khối thành Flex Container. flex-direction: row (trục ngang mặc định) hoặc column (xếp chồng dọc từ trên xuống).

CSS 
.container {
  display: flex;
  flex-direction: row; /* hoặc column */
  gap: 16px;
}
justify-content Căn Chỉnh Trục Chính (Main Axis)

Căn chỉnh các phần tử con dọc theo trục chính: center, space-between (đẩy đều sang 2 bên), space-around, flex-start, flex-end.

CSS 
.nav-bar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
align-items & align-self Căn Chỉnh Trục Phụ (Cross Axis)

align-items căn chỉnh tất cả con theo trục vuông góc: center, flex-start, flex-end, stretch. align-self ghi đè cho 1 con riêng lẻ.

CSS 
.center-all {
  display: flex;
  justify-content: center;
  align-items: center; /* Căn giữa cả 2 trục */
}
.special-item {
  align-self: flex-end;
}
flex-wrap & gap Tự Động Xuống Dòng & Khoảng Cách

flex-wrap: wrap cho phép các phần tử tự động xuống hàng mới khi hết chỗ. gap tạo khoảng cách đều giữa các phần tử mà không cần margin âm.

CSS 
.cards-row {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}
flex: 1 (flex-grow, shrink, basis) Tỷ Lệ Co Giãn Của Item

flex: 1 viết tắt của flex-grow: 1 (chiếm toàn bộ không gian còn trống), flex-shrink: 1 (cho phép co lại), flex-basis: 0%.

CSS 
.content-main {
  flex: 1; /* Chiếm trọn không gian trống */
}
.sidebar {
  flex: 0 0 280px; /* Cố định 280px */
}

4.6 Bố Cục 2 Chiều CSS Grid (CSS Grid Layout)

display: grid & grid-template-columns Khởi Tạo Bố Cục Lưới 2 Chiều

Chia layout thành lưới đa chiều. repeat(auto-fit, minmax(280px, 1fr)) là công thức vàng giúp responsive hoàn hảo không cần media queries.

CSS 
.grid-auto-layout {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
}
grid-column & grid-row Mở Rộng Ô Trong Lưới Grid

Quy định một phần tử con bắt đầu và kết thúc ở đường kẻ nào, hoặc gộp bao nhiêu ô (span). grid-column: 1 / -1 chiếm trọn bề ngang.

CSS 
.featured-banner {
  grid-column: 1 / -1; /* Trải dài toàn bộ hàng */
}
.tall-card {
  grid-row: span 2; /* Chiếm 2 hàng cao */
}
grid-template-areas Bố Cục Vẽ Sơ Đồ Trực Quan

Vẽ cấu trúc toàn bộ trang web (header, sidebar, content, footer) bằng các chuỗi tên chữ trực quan dễ đọc.

CSS 
.app-layout {
  display: grid;
  grid-template-areas:
    'header header'
    'sidebar content'
    'footer  footer';
  grid-template-columns: 260px 1fr;
}
.site-header { grid-area: header; }
.site-sidebar { grid-area: sidebar; }

4.7 Định Dạng Kiểu Chữ & Phông Chữ (Typography & Text)

font-family & Google Fonts Phông Chữ Hệ Thống & Web Fonts

Khai báo thứ tự ưu tiên phông chữ. Luôn kết thúc bằng sans-serif hoặc serif để dự phòng khi phông ngoài chưa tải kịp.

CSS 
body {

code, pre {

font-size, font-weight & line-height Cỡ Chữ, Độ Đậm & Giãn Dòng

font-weight từ 100 đến 900 (400: thường, 600: semi-bold, 700: bold). line-height tỷ lệ lý tưởng cho đoạn văn là 1.5 đến 1.7.

CSS 
h1 {
  font-size: 2.5rem;
  font-weight: 800;
  line-height: 1.2;
}
p {
  font-size: 1rem;
  line-height: 1.6;
}
text-align & text-transform Căn Lề & Chuyển Đổi Chữ Hoa

text-align: left, center, right, justify. text-transform: uppercase (chữ hoa toàn bộ), capitalize (viết hoa chữ cái đầu từng từ).

CSS 
.section-header {
  text-align: center;
}
.badge-caps {
  text-transform: uppercase;
  letter-spacing: 0.05em;

5. Bảng Tra Cứu JavaScript Toàn Diện

5.1 Biến, Kiểu Dữ Liệu & Toán Tử Hiện Đại

const vs let vs var Khai Báo Biến Chuẩn ES6

const: khai báo hằng số không gán lại được (khuyên dùng mặc định). let: khai báo biến có thể gán lại trong phạm vi block {}. Tránh dùng var vì tính hoisting gây lỗi scope.

JavaScript 
const API_KEY = 'secret_123'; // Không thể gán lại
let counter = 0;
counter += 1; // Hợp lệ
typeof & 8 Kiểu Dữ Liệu Kiểm Tra Kiểu Dữ Liệu Nguyên Bản

7 kiểu nguyên thủy: string, number, boolean, null, undefined, symbol, bigint và kiểu phức hợp: object (bao gồm cả mảng array).

JavaScript 
typeof 'DevWeb'   // 'string'
typeof 42         // 'number'
typeof true       // 'boolean'
typeof undefined  // 'undefined'
typeof null       // 'object' (lỗi lịch sử JS)
typeof [1, 2, 3]  // 'object' (kiểm tra Array.isArray())
=== vs == (Toán Tử So Sánh) So Sánh Nghiêm Ngặt

Luôn dùng === và !== để so sánh cả giá trị lẫn kiểu dữ liệu, tránh lỗi ép kiểu ngầm nguy hiểm của toán tử ==.

JavaScript 
5 === '5' // false (number khác string)
5 == '5'  // true (ép kiểu ngầm - NGUY HIỂM)
0 === false // false
&&, ||, ?? (Toán Tử Logic) Toán Tử Điều Kiện Rút Gọn

&& (AND), || (OR nhận giá trị đầu tiên truthy), ?? (Nullish Coalescing chỉ lấy mặc định nếu giá trị là null hoặc undefined).

JavaScript 
const title = user.name || 'Khách'; // Nếu '' vẫn lấy 'Khách'
const count = user.score ?? 0;   // Nếu 0 vẫn giữ nguyên 0!
Template Literals (``) Chuỗi Nội Suy Hiện Đại

Sử dụng dấu backtick (`) để nhúng biến ${tenBien}, biểu thức tính toán và viết chuỗi nhiều dòng mà không cần dấu cộng nối chuỗi.

JavaScript 
const name = 'An';
const score = 95;
const msg = `Chúc mừng ${name}! Điểm số: ${score + 5}/100.`;

Cú pháp ngắn gọn thay thế if-else cho các phép gán biến hoặc điều kiện nội dòng: dieuKien ? khiDung : khiSai.

JavaScript 
const isLoggedIn = true;
const statusText = isLoggedIn ? 'Đã đăng nhập' : 'Khách vãng lai';

5.2 Cấu Trúc Rẽ Nhánh & Vòng Lặp (Conditionals & Loops)

if ... else if ... else Cấu Trúc Rẽ Nhánh Điều Kiện

Thực thi khối mã lệnh tương ứng khi biểu thức điều kiện trả về giá trị đúng (truthy).

JavaScript 
const score = 85;
if (score >= 90) {
  console.log('Xuất sắc');
} else if (score >= 70) {
  console.log('Khá tốt');
} else {
  console.log('Cần cố gắng');
}
switch ... case ... default Rẽ Nhánh Theo Nhiều Trường Hợp

So sánh một giá trị với nhiều trường hợp (case). Luôn có câu lệnh break ở cuối mỗi case và khối default xử lý ngoại lệ.

JavaScript 
switch (role) {
  case 'admin':
    grantAllAccess();
    break;
  case 'editor':
    grantEditAccess();
    break;
  default:
    grantReadAccess();
}
for (let i = 0; i < n; i++) Vòng Lặp Truyền Thống

Lặp qua một khoảng số nguyên với biến đếm i, thường dùng khi cần biết chính xác chỉ số lặp index.

JavaScript 
const items = ['HTML', 'CSS', 'JavaScript'];
for (let i = 0; i < items.length; i++) {
  console.log(`${i + 1}. ${items[i]}`);
}
for ... of (Mảng & Chuỗi) Duyệt Giá Trị Mảng Tiện Lợi

Cú pháp lặp hiện đại và gọn gàng nhất để duyệt qua từng giá trị (value) của mảng hoặc từng ký tự trong chuỗi.

JavaScript 
const fruits = ['Táo', 'Cam', 'Xoài'];
for (const fruit of fruits) {
  console.log(fruit);
}
for ... in (Thuộc Tính Object) Duyệt Tên Thuộc Tính Khóa

Duyệt qua tất cả các tên khóa (keys) của một Object thuần túy.

JavaScript 
const user = { name: 'Nam', age: 22, city: 'Hà Nội' };
for (const key in user) {
  console.log(`${key}: ${user[key]}`);
}

while: kiểm tra điều kiện trước khi lặp. do...while: luôn thực thi khối lệnh ít nhất 1 lần trước khi kiểm tra điều kiện.

JavaScript 
let count = 3;
while (count > 0) {
  console.log(count);
  count--;
}

5.3 Hàm (Functions), Arrow Functions & Scope

Function Declaration vs Arrow Function Hàm Truyền Thống & Hàm Mũi Tên

Hàm mũi tên () => {} có cú pháp cực kỳ ngắn gọn, tự động bind giá trị this từ ngữ cảnh cha bao quanh.

JavaScript 
// Khai báo truyền thống
function add(a, b) {
  return a + b;
}

// Arrow Function ngắn gọn (return ngầm định)
const multiply = (a, b) => a * b;
Default Parameters & Rest (...args) Tham Số Mặc Định & Gom Tham Số

Gán giá trị mặc định cho tham số nếu không được truyền vào; dùng cú pháp rest (...args) để nhận vô số đối số dưới dạng mảng.

JavaScript 
// Tham số mặc định
function greet(name = 'Bạn') {
  return `Xin chào ${name}!`;
}

// Rest parameters nhận nhiều tham số
function sumAll(...numbers) {
  return numbers.reduce((sum, n) => sum + n, 0);
}
Closures & Block Scope Phạm Vi Khối & Đóng Gói Biến

Hàm con bên trong luôn có quyền truy cập vào các biến của hàm cha bao bọc nó ngay cả khi hàm cha đã kết thúc thực thi.

JavaScript 
function createCounter() {
  let count = 0; // Biến private đóng gói
  return {
    increment: () => ++count,
    getCount: () => count
  };
}
const c = createCounter();
c.increment(); // 1

5.4 Mảng Toàn Diện (Array Methods Chuẩn W3Schools)

push(), pop(), shift(), unshift() Thêm & Xóa Phần Tử Mảng

push() thêm vào cuối, pop() xóa phần tử cuối. unshift() thêm vào đầu, shift() xóa phần tử đầu mảng.

JavaScript 
const arr = [1, 2, 3];
arr.push(4);    // [1, 2, 3, 4]
arr.pop();       // [1, 2, 3] (trả về 4)
arr.unshift(0);  // [0, 1, 2, 3]
arr.shift();     // [1, 2, 3] (trả về 0)
map() Biến Đổi Từng Phần Tử Mảng

Tạo ra một mảng mới bằng cách áp dụng hàm biến đổi cho từng phần tử của mảng gốc mà không làm thay đổi mảng cũ.

JavaScript 
const numbers = [1, 2, 3, 4];
const doubled = numbers.map(n => n * 2); // [2, 4, 6, 8]

const names = users.map(u => u.name);
filter() Lọc Phần Tử Thỏa Mãn Điều Kiện

Tạo ra một mảng mới chỉ chứa các phần tử trả về kết quả true khi đi qua hàm kiểm tra điều kiện.

JavaScript 
const scores = [45, 88, 72, 95, 60];
const passed = scores.filter(score => score >= 70); // [88, 72, 95]
reduce() Tích Lũy Giá Trị Toàn Bộ Mảng

Thu gọn toàn bộ các phần tử trong mảng về duy nhất một giá trị (tính tổng tiền giỏ hàng, đếm số lần xuất hiện).

JavaScript 
const cart = [{ price: 100 }, { price: 200 }, { price: 50 }];
const total = cart.reduce((sum, item) => sum + item.price, 0); // 350
find() & findIndex() Tìm Kiếm Phần Tử Đầu Tiên

find() trả về giá trị của phần tử đầu tiên thỏa điều kiện (hoặc undefined). findIndex() trả về vị trí index (hoặc -1).

JavaScript 
const users = [{ id: 1, name: 'An' }, { id: 2, name: 'Bình' }];
const user = users.find(u => u.id === 2); // { id: 2, name: 'Bình' }
includes(), some() & every() Kiểm Tra Sự Tồn Tại

includes() kiểm tra giá trị có trong mảng. some() kiểm tra có ít nhất 1 phần tử thỏa mãn. every() kiểm tra tất cả phần tử đều thỏa.

JavaScript 
const roles = ['user', 'editor'];
roles.includes('admin'); // false

const nums = [2, 4, 6];
nums.every(n => n % 2 === 0); // true (tất cả là chẵn)
slice() vs splice() Cắt Sao Chép & Sửa Xóa Mảng Gốc

slice(start, end): sao chép một đoạn mảng con (an toàn, không đổi mảng gốc). splice(start, count, items): xóa hoặc chèn trực tiếp làm đổi mảng gốc.

JavaScript 
const letters = ['a', 'b', 'c', 'd'];
const sub = letters.slice(1, 3); // ['b', 'c'] (letters giữ nguyên)

letters.splice(1, 1, 'Z'); // Thay 'b' bằng 'Z'
Spread Operator: [...arr] Nhân Bản & Gộp Mảng Nhanh Chóng

Trải rộng các phần tử để nhân bản bản sao (shallow copy) hoặc gộp nhiều mảng lại với nhau cực kỳ ngắn gọn.

JavaScript 
const a = [1, 2];
const b = [3, 4];
const combined = [...a, ...b, 5]; // [1, 2, 3, 4, 5]
const clone = [...a]; // Sao chép không tham chiếu

5.5 Chuỗi Ký Tự (String Methods)

trim(), toLowerCase() & toUpperCase() Chuẩn Hóa Chuỗi Nhập Liệu

trim() loại bỏ khoảng trắng thừa ở 2 đầu chuỗi (cực kỳ quan trọng khi xử lý ô tìm kiếm hoặc form đăng nhập).

JavaScript 
const raw = '   Admin@DevWebLab.com   ';
const clean = raw.trim().toLowerCase(); // 'admin@devweblab.com'
includes(), startsWith() & endsWith() Kiểm Tra Khớp Mẫu Chuỗi

Kiểm tra chuỗi có chứa từ khóa, bắt đầu bằng tiền tố hoặc kết thúc bằng phần mở rộng chỉ định.

JavaScript 
const url = 'https://devweblab.com/avatar.png';
url.startsWith('https://'); // true
url.endsWith('.png');      // true
url.includes('devweb');    // true
split() & join() Chuyển Đổi Giữa Chuỗi & Mảng

split(delimiter) cắt chuỗi thành mảng theo ký tự phân tách. join(separator) nối mảng các phần tử lại thành một chuỗi.

JavaScript 
const tagString = 'html,css,javascript,react';
const tags = tagString.split(','); // ['html', 'css', 'javascript', 'react']
const reassembled = tags.join(' • ');
replace() & replaceAll() Tìm Kiếm & Thay Thế Ký Tự

replace() thay thế từ đầu tiên tìm thấy hoặc theo Regex. replaceAll() thay thế toàn bộ mọi vị trí xuất hiện.

JavaScript 
const str = 'apple, banana, apple';
const fixed = str.replaceAll('apple', 'orange'); // 'orange, banana, orange'

5.6 Đối Tượng (Objects), Destructuring & JSON

Object Destructuring ({ a, b }) Phân Rã Thuộc Tính Đối Tượng

Trích xuất nhanh các trường dữ liệu từ đối tượng vào các biến độc lập, hỗ trợ đổi tên biến và đặt giá trị mặc định.

JavaScript 
const user = { id: 101, username: 'an_dev', role: 'admin' };
const { username, role, status = 'active' } = user;
console.log(username, role); // 'an_dev', 'admin'
Object Spread: { ...obj } Sao Chép & Ghi Đè Thuộc Tính

Tạo bản sao object mới hoặc cập nhật một vài trường dữ liệu theo tư duy bất biến (immutable state).

JavaScript 
const prevSettings = { theme: 'dark', sound: true };
const newSettings = {
  ...prevSettings,
  sound: false // Ghi đè giá trị
};
Object.keys(), values(), entries() Trích Xuất Dữ Liệu Đối Tượng

Lấy toàn bộ danh sách tên khóa (keys), mảng giá trị (values), hoặc mảng các cặp [key, value] để duyệt lặp.

JavaScript 
const stats = { views: 120, likes: 45, shares: 12 };
Object.keys(stats);   // ['views', 'likes', 'shares']
Object.values(stats); // [120, 45, 12]
Object.entries(stats).forEach(([k, v]) => console.log(k, v));
Optional Chaining (?.) Truy Cập An Toàn Thuộc Tính Sâu

Ngăn chặn lỗi sập trang web kinh điển 'Cannot read property of undefined' khi đọc dữ liệu lồng sâu chưa kịp tải từ API.

JavaScript 
const user = { profile: null };
// Không bị ném lỗi TypeError!
const city = user.profile?.address?.city ?? 'Chưa cập nhật';
JSON.stringify() & JSON.parse() Chuyển Đổi Dữ Liệu JSON Chuẩn

stringify chuyển đối tượng JS thành chuỗi JSON lưu vào LocalStorage/gửi API; parse dịch ngược chuỗi thành Object (kèm try-catch an toàn).

JavaScript 
const data = { id: 1, name: 'WebLab' };
const jsonStr = JSON.stringify(data);

try {
  const parsed = JSON.parse(jsonStr);
} catch (err) {
  console.error('Lỗi định dạng JSON:', err);
}

5.7 Thao Tác DOM: Chọn & Duyệt Cây DOM (DOM Selection)

document.querySelector() Chọn Phần Tử Đầu Tiên Khớp CSS

Truy xuất phần tử đầu tiên khớp với chuỗi CSS Selector (class, id, thẻ, thuộc tính). Trả về null nếu không tìm thấy.

JavaScript 
const heading = document.querySelector('.main-title');
const submitBtn = document.querySelector('button[type="submit"]');
document.querySelectorAll() Chọn Tất Cả Phần Tử (NodeList)

Truy xuất danh sách tĩnh NodeList chứa tất cả các phần tử khớp CSS Selector. Có sẵn phương thức forEach() để duyệt lặp.

JavaScript 
const cards = document.querySelectorAll('.card');

button.addEventListener('click', (e) => {

const list = document.querySelector('.task-list');
const totalTasks = list.children.length;
const firstTask = list.firstElementChild;

5.9 Xử Lý Sự Kiện & Event Delegation (DOM Events)

addEventListener(event, handler) Lắng Nghe Sự Kiện Chuẩn

Đăng ký hàm lắng nghe sự kiện chuẩn W3C (click, input, change, submit, keydown). Cho phép gắn nhiều listener độc lập.

JavaScript 
const btn = document.getElementById('saveBtn');
btn.addEventListener('click', (event) => {

e.preventDefault() & e.stopPropagation() Chặn Mặc Định & Chặn Nổi Bọt

e.preventDefault(): ngăn hành vi mặc định (chặn reload trang khi submit form, chặn chuyển trang thẻ link). e.stopPropagation(): ngăn nổi bọt lên cha.

JavaScript 
const form = document.querySelector('form');

});

document.getElementById('taskList').addEventListener('click', (e) => {

5.10 Bất Đồng Bộ, REST API & Web APIs (Async / Await)

setTimeout: thực thi hàm sau một khoảng thời gian trễ (ms). setInterval: lặp lại định kỳ đều đặn (nhớ dọn dẹp bằng clearInterval).

JavaScript 
const timerId = setTimeout(() => {
  console.log('Chạy sau 2 giây');

// Hủy hẹn giờ nếu cần: clearTimeout(timerId);
async / await & try ... catch Lập Trình Bất Đồng Bộ Hiện Đại

Viết mã bất đồng bộ phẳng và tự nhiên như mã đồng bộ tuần tự, dễ dàng bắt lỗi toàn diện với khối try ... catch.

JavaScript 
async function loadWeather(city) {
  try {
    const res = await fetch(`https://api.example.com/weather?city=${city}`);
    if (!res.ok) throw new Error(`HTTP Error: ${res.status}`);
    const data = await res.json();
    return data;
  } catch (err) {
    console.error('Lỗi khi tải thời tiết:', err);
  }
}

Phương thức native gọi API không cần cài thêm thư viện. Luôn kiểm tra res.ok trước khi đọc nội dung res.json().

JavaScript 
fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'DevWeb' })

.then(res => res.json())
.then(data => console.log(data));

Lưu trữ dữ liệu dạng cặp key-value trong trình duyệt. localStorage lưu vĩnh viễn, sessionStorage tự xóa khi đóng tab.

async function copyCode(text) {

  }
}
