1. Bảng Thẻ HTML Cốt Lõi & Kết Quả Trực Quan

Phân biệt thẻ có đóng mở vs thẻ tự đóng, nhìn thấy tận mắt từng thẻ hiển thị ra sao.

Mọi trang web đều được tạo nên từ các thẻ HTML. Hãy quan sát bảng tra cứu nhanh dưới đây:

Tên thẻ Loại thẻ Mục đích sử dụng Code mẫu
<h1> ... <h6> Thẻ cặp (Có đóng) Tiêu đề các cấp (`h1` to nhất, `h6` nhỏ nhất) <h1>Tiêu đề trang</h1>
<p> Thẻ cặp Đoạn văn bản thông thường <p>Nội dung văn bản...</p>
<a> Thẻ cặp Tạo đường link bấm vào để nhảy trang (href) <a href="https://...">Bấm vào đây</a>
<img> Thẻ tự đóng (Không có </img>) Chèn hình ảnh (src = nguồn ảnh, alt = mô tả) <img src="avatar.jpg" alt="Ảnh">
<button> Thẻ cặp Nút bấm tương tác <button>Đăng Ký</button>
<input> Thẻ tự đóng Ô nhập văn bản, mật khẩu, checkbox... <input type="text" placeholder="Nhập tên">
<div> Thẻ cặp (Khối Block) Chiếc hộp rỗng dùng để gom nhiều thẻ con lại <div class="card">...</div>
<span> Thẻ cặp (Nội tuyến Inline) Gom một vài chữ trong câu để đổi màu riêng Giá: <span class="gia">50k</span>

💡 Điểm khác biệt quan trọng: Thẻ Khối (<div>, <p>) vs Thẻ Nội Tuyến (<span>, <a>)

Thẻ Khối (Block): Luôn tự động xuống dòng và chiếm trọn 100% bề ngang.

<div> Hộp 1 (Chiếm cả dòng) </div>
<div> Hộp 2 (Tự rớt xuống dòng mới) </div>

Thẻ Nội Tuyến (Inline): Đứng cùng nhau trên 1 hàng, chỉ chiếm đúng độ dài chữ.

Đoạn văn có <span> Chữ 1 </span> và <span> Chữ 2 </span> nằm chung 1 hàng!

2. Bản Đồ Đường Dẫn (File Paths) - Không Bao Giờ Mất Ảnh/CSS

Nguyên tắc "Đứng từ file HTML hiện tại để nhìn sang file cần gọi".

Bấm chọn tình huống bên dưới để xem đường dẫn viết như thế nào là chính xác:

📁 TKW (Thư mục gốc) ├── 📄 index.html ├── 📁 assets/ │ └── 📁 css/ │ └── 🎨 hub-style.css └── 📁 bai-01-profile-card/ └── 📁 solution/ ├── 📄 index.html <-- [BẠN ĐANG ĐỨNG TẠI ĐÂY] └── 🎨 style.css <-- [CẦN GỌI FILE NÀY]

Tình huống 1: Hai file nằm cạnh nhau

File style.css nằm cùng thư mục solution/ với file index.html. Ta chỉ cần viết thẳng tên file!

<link rel="stylesheet" href="style.css">

4. Dấu Hai Chấm `:` (Pseudo-classes) - Bắt Trọn Mọi Tương Tác

CSS không chỉ tĩnh, nó thay đổi khi người dùng rê chuột (:hover), click gõ (:focus), hay bấm giữ (:active).

/* 1. Khi RÊ CHUỘT VÀO: :hover */ .nut-bam:hover { background-color: #4f46e5; transform: translateY(-3px); } /* 2. Khi BẤM GIỮ CHUỘT: :active */ .nut-bam:active { transform: scale(0.95); } /* 3. Khi CLICK GÕ CHỮ: :focus */ input:focus { border-color: #10b981; box-shadow: 0 0 0 4px rgba(16, 185, 129, 0.2); }

5. Đấu Trường Độ Ưu Tiên: Ai Mạnh Hơn Ai?

Khi 2 luật CSS cùng đổi màu một dòng chữ, trình duyệt sẽ nghe theo ai?

Bảng xếp hạng quyền lực từ mạnh nhất đến yếu nhất:

1
!important

Mức ưu tiên rất cao trong CSS cascade (thứ tự ưu tiên chuẩn còn phụ thuộc vào nguồn gốc style, cascade layer, specificity và source order; nên hạn chế lạm dụng).

color: red !important;
2
Inline Style (Style viết trực tiếp trên thẻ)

Viết trực tiếp vào thuộc tính của thẻ HTML.

<p style="color: yellow;">
3
#ID Selector (Dấu thăng)

Định danh cá nhân duy nhất, mạnh hơn mọi Class.

#tieu-de { color: blue; }
4
.Class Selector (Dấu chấm)

Mặc đồng phục cho nhiều thẻ, mạnh hơn tên thẻ đơn thuần.

.chu-xanh { color: green; }
5
Tên Thẻ (Tag Selector)

Yếu nhất trong các loại bộ chọn cụ thể.

p { color: black; }
