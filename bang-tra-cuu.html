3. Bảng Tra Cứu HTML5 Semantic

Các thẻ cấu trúc ngữ nghĩa cốt lõi giúp chuẩn SEO, hỗ trợ bộ đọc màn hình (A11y) và code sạch.

<header> Khối Đầu Trang

Chứa phần đầu trang, logo, thanh điều hướng chính, hoặc phần giới thiệu của một bài viết/card.

HTML5 MẪU 
<header class="site-header">
  <a href="/" class="logo">⚡ DevWeb</a>
  <nav class="main-nav">...</nav>
</header>
<nav> Điều Hướng

Vùng chứa các liên kết điều hướng quan trọng (Menu chính, thanh phụ, phân trang).

HTML5 MẪU 
<nav aria-label="Menu chính">
  <ul>
    <li><a href="#home">Trang Chủ</a></li>
    <li><a href="#labs">Phòng Lab</a></li>
  </ul>
</nav>
<main> Nội Dung Chính

Khối nội dung chính và độc nhất của trang. Mỗi trang HTML chỉ được có duy nhất 1 thẻ <main>.

HTML5 MẪU 
<main id="main-content">
  <h1>Tiêu Đề Bài Viết</h1>
  <p>Nội dung cốt lõi của trang...</p>
</main>
<article> Khối Độc Lập

Đại diện cho khối nội dung hoàn chỉnh, có thể trích xuất đứng riêng (bài blog, sản phẩm, bình luận).

HTML5 MẪU 
<article class="blog-post">
  <h2>Hướng Dẫn CSS Grid</h2>
  <time datetime="2026-09-25">25/09/2026</time>
  <p>Tìm hiểu bố cục dạng lưới...</p>
</article>
<section> Phần Nội Dung

Gom nhóm nội dung theo một chủ đề cụ thể (thường đi kèm thẻ tiêu đề <h2>-<h6>).

HTML5 MẪU 
<section class="features-section">
  <h2>Tính Năng Nổi Bật</h2>
  <div class="grid-3">...</div>
</section>
<aside> Nội Dung Phụ

Khu vực bên lề, thanh bên (Sidebar), danh sách bài viết liên quan, quảng cáo hoặc ghi chú thêm.

HTML5 MẪU 
<aside class="sidebar">
  <h3>Bài Viết Mới Nhất</h3>
  <ul>...</ul>
</aside>
<footer> Chân Trang

Chân trang web hoặc chân một thẻ bài viết (chứa bản quyền, thông tin tác giả, liên kết chính sách).

HTML5 MẪU 
<footer class="site-footer">
  <p>&copy; 2026 DevWeb Lab.</p>
</footer>
<figure> + <figcaption> Hình Ảnh & Chú Thích

Gói hình ảnh minh họa, sơ đồ cùng dòng chú thích tiêu đề bên dưới một cách chuẩn ngữ nghĩa.

HTML5 MẪU 
<figure>
  <img src="preview.jpg" alt="Mô hình">
  <figcaption>Hình 1: Trục Flexbox</figcaption>
</figure>
<details> + <summary> Đóng/Mở Native

Tạo khối thu gọn / mở rộng nội dung (Accordion / FAQ) thuần túy bằng HTML không cần viết một dòng JS nào.

HTML5 MẪU 
<details>
  <summary>Xem gợi ý giải bài</summary>
  <p>Sử dụng display: flex...</p>
</details>

4. Bảng Tra Cứu CSS Flexbox (Cực Kỳ Hay Dùng)

Căn chỉnh một chiều (dọc hoặc ngang), co giãn phần tử linh hoạt và dàn layout nhanh chóng.

🎮 Thử nghiệm trực quan:
01
02
03
MẪU CSS FLEXBOX CHUẨN 
.flex-container {
  display: flex;                  /* Kích hoạt Flexbox */
  flex-direction: row;            /* Trục chính: row (ngang) | column (dọc) */
  justify-content: center;        /* Căn chỉnh trục chính: flex-start | center | flex-end | space-between | space-around */
  align-items: center;            /* Căn chỉnh trục phụ: stretch | flex-start | center | flex-end */
  gap: 16px;                      /* Khoảng cách giữa các con */
  flex-wrap: wrap;                /* Tự xuống dòng khi màn hình hẹp */
}

5. Bảng Tra Cứu CSS Grid (Bố Cục Đa Cột Đỉnh Cao)

Xây dựng lưới 2 chiều (hàng và cột đồng thời) cực mạnh mẽ cho danh sách thẻ, sản phẩm, dashboard.

1 DÒNG TỰ ĐỘNG RESPONSIVE LƯỚI KHÔNG CẦN MEDIA QUERY 
.grid-responsive {
  display: grid;
  /* Tự động chia cột theo màn hình, tối thiểu 280px, tối đa 1fr */
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 24px;
}
GRID CỐ ĐỊNH 3 CỘT (HOẶC CHIA TỈ LỆ 1:2:1) 
/* Lưới 3 cột đều nhau */
.grid-3-col {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

/* Bố cục Sidebar + Main Content */
.layout-sidebar-main {
  display: grid;
  grid-template-columns: 280px 1fr;
  gap: 30px;
}

6. Bảng Tra Cứu CSS Responsive & Media Queries

Các điểm ngắt (Breakpoints) tiêu chuẩn quốc tế giúp giao diện mượt mà trên mọi thiết bị.

CÁC BREAKPOINTS CHUẨN THỰC CHIẾN 
/* 1. Màn hình Tablet & Điện thoại (< 768px) */
@media (max-width: 768px) {
  .container {
    padding: 0 16px;
  }
  .hero-layout {
    flex-direction: column;
    text-align: center;
  }
}

/* 2. Màn hình Mobile nhỏ (< 480px) */
@media (max-width: 480px) {
  .hero-title {
    font-size: 1.8rem;
  }
  .btn-group {
    width: 100%;
    flex-direction: column;
  }
}

/* 3. Chế độ giảm tải hoạt họa (A11y & Hiệu năng) */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

7. Bảng Tra Cứu JavaScript DOM Manipulation & Web APIs

Những câu lệnh JavaScript phổ biến nhất khi xây dựng trang web tương tác hiện đại.

querySelector Chọn Phần Tử

Chọn 1 phần tử đầu tiên hoặc toàn bộ mảng phần tử phù hợp với CSS selector.

JAVASCRIPT 
// Chọn 1 phần tử
const btn = document.querySelector('#btn');
const tab = document.querySelector('.tab.active');

// Chọn danh sách tất cả phần tử
const cards = document.querySelectorAll('.card');
cards.forEach(c => console.log(c));
addEventListener Lắng Nghe Sự Kiện

Bắt các hành động của người dùng như bấm chuột (click), gõ phím (keydown), submit form.

JAVASCRIPT 
btn.addEventListener('click', (e) => {
  e.preventDefault();
  console.log('Đã click!');
});

// Phím tắt bàn phím
window.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') closeModal();
});
classList Thao Tác Class CSS

Bật, tắt, thêm hoặc xóa class CSS để kích hoạt hiệu ứng hoạt họa và thay đổi giao diện.

JAVASCRIPT 
el.classList.add('visible');   // Thêm
el.classList.remove('hidden'); // Xóa
el.classList.toggle('active'); // Bật/tắt

// Kiểm tra có class hay không
if (el.classList.contains('active')) {
  // Logic khi đang active
}
localStorage Lưu Trữ An Toàn

Lưu trữ dữ liệu trong trình duyệt của người dùng (kèm cấu trúc try...catch chống lỗi phân tích cú pháp).

JAVASCRIPT (SAFE PATTERN) 
// Lưu mảng/object
localStorage.setItem('todos', JSON.stringify(data));

// Đọc an toàn với try...catch
let items = [];
try {
  const raw = localStorage.getItem('todos');
  items = raw ? JSON.parse(raw) : [];
} catch (e) {
  items = [];
}
fetch() & async/await Gọi API Bất Đồng Bộ

Truy xuất dữ liệu từ máy chủ API REST, hiển thị spinner và bắt lỗi mạng chuyên nghiệp.

JAVASCRIPT ASYNC/AWAIT 
async function loadData(url) {
  try {
    const res = await fetch(url);
    if (!res.ok) throw new Error(res.status);
    const data = await res.json();
    return data;
  } catch (err) {
    console.error('Lỗi tải API:', err);
  }
}
textContent vs innerHTML Gán Nội Dung An Toàn

Sử dụng textContent cho văn bản từ người dùng (chống tấn công XSS) và innerHTML khi cần chèn thẻ HTML.

JAVASCRIPT 
// 🛡️ AN TOÀN: Chống XSS từ người dùng
element.textContent = userMessage;

// ⚡ Chèn HTML từ nguồn tin cậy
card.innerHTML = `<h3>${title}</h3>`;
Đã sao chép mã nguồn vào bộ nhớ tạm!
