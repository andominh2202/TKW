CSS Variables & LocalStorage

Trải Nghiệm Hệ Thống Giao Diện Sáng / Tối Mượt Mà

Toàn bộ màu nền, văn bản, độ bóng và đường viền được điều khiển bởi CSS Custom Properties (:root). Nhấp vào nút ở góc trên để thấy sự chuyển đổi màu sắc êm ái mà không bị giật lag.

🎨

CSS Custom Properties

Khai báo --bg-primary, --text-primary ở :root và ghi đè lại trong bộ chọn [data-theme="dark"].

var(--bg-card)
💾

Ghi Nhớ LocalStorage

Lưu trạng thái vào trình duyệt để khi người dùng tải lại trang hoặc mở tab mới, giao diện vẫn giữ nguyên lựa chọn yêu thích.

localStorage.setItem()
🌓

Tự Động Theo Hệ Thống

Hỗ trợ kiểm tra prefers-color-scheme để tự động chuyển sang Dark Mode nếu máy tính người dùng đang bật Dark Mode.

window.matchMedia()
